Power BI Report Configuration Required

Connect your Microsoft Power BI Service workspace to embed interactive Power BI dashboards directly into RouteX.

How to configure Microsoft Power BI:

  1. Register an Azure Active Directory / Entra ID Application with Report.Read.All permissions.
  2. Add the Service Principal to your Power BI Workspace with Viewer access.
  3. Set server environment variables: POWERBI_TENANT_ID, POWERBI_CLIENT_ID, POWERBI_CLIENT_SECRET, POWERBI_WORKSPACE_ID, POWERBI_REPORT_ID.
  4. Or configure POWERBI_REPORT_URL with a direct secure embed link.
Paste any valid Power BI report embed link to preview instantly without restarting the server.
